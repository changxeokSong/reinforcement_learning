# 레이저 미션 실험과 제출 근거

직접 만든 Unity 환경에서 정책 하나가 처음 보는 레이저 배치의 10단계를 연속 완주하는지 검증했다. 단계별 성공률은 각 단계를 따로 시작해서 구한다. 순차 완주율은 1단계부터 모두 통과한 캠페인의 비율이며, 첫 시도와 단계당 최대 세 번 시도를 구분한다.

## 실험에서 확인한 변화

| 문제 | 적용한 방법과 비교 조건 | 결과와 해석 | 확인 자료 |
|---|---|---|---|
| 초기 PPO가 레이저 앞에서 멈춤 | 시간 비용, 슬라이딩, 레이저 높이 관측을 순차 수정 | 1단계 예비 성공률 0% → 약 10% → 25% → 90%. 별도 실험에서 관측 변경만의 효과는 작았다. | [초기 수정과 재검증](laser.md#설계를-고친-과정) |
| SAC의 Q값 발산 | 기울기 제한 조건에서 Bellman 목표값만 ±3으로 제한 | 같은 빌드와 시드에서 1~4단계 평균 54% → 93%. 실패 시드는 0% → 97%. | [SAC 안정화](results.md#x6x7-sac-안정화) |
| 고정 배치에서 정책 하나가 완주하지 못함 | 단계별 PPO 전문가를 BC·DAgger 학생 하나에 학습시키고, 이후 미해결 10단계 배치의 탐색 시범 추가 | 초기 단일 정책 0/600, BC·DAgger 각각 361/600. 시범을 추가한 후 고정 배치에서 학생 6개 합계 1,200/1,200회 완주. | [모방 학습 구현](../laser/imitation.py) · [시범 후 평가](results.md#10단계-마지막-배치-ppo-집중-학습-실패--시범으로-해결) |
| 고정 배치 학습의 일반화 부족 | 절차 생성 배치에서 전문가를 다시 학습하고, 학생 크기·데이터 예산을 맞춘 BC와 DAgger를 비교 | 새 배치의 단계 평균 48.9% → 60.4%(+11.5%p). 학생 크기·회차·데이터를 함께 늘린 DAgger는 80.0%. 더 강한 SAC 전문가로 교체했을 때 학생은 약 63%로 하락했다. | [새 배치에서의 정책 증류](results.md#일반화-처음-보는-배치) |
| 6단계의 좁은 이동 통로 | 같은 DAgger 가중치와 평가 시드에서 벽 간격·통로 폭 변경 | 단독 성공률 17.5% → 29.0%, 순차 완주 253/600 → 352/600. 게임 설계를 바꾼 결과다. | [환경 수정과 재평가](results.md#unity-설계-수정-후-재평가) |
| 하이퍼파라미터 선택 편향 | 탐색 시드 3개와 확인 시드 5개를 분리해 PPO 학습률, SAC 갱신 빈도, DQN 조합을 검증 | 단계 평균이 PPO +7.6%p, SAC +22.3%p 개선됐다(Holm 보정 후 유의). DQN +2.8%p는 확인 실험에서 불확실했다. | [확인 실험](results.md#새-seed로-확인-c) · [실험 설정](../laser/experiments.py) |
| PPO의 순차 완주 병목 | 튜닝한 PPO 학습량 확대 후 최종 정책을 고정해 0.2초 충돌 예측을 비교 | 단계 평균 47.7% → 78.9%. 같은 최종 PPO의 새 배치 완주 440/1,000 → 1,000/1,000. 예측은 실행 시 Unity 내부 상태를 사용한다. | [긴 학습 및 예측 비교](results.md#더-긴-학습과-실행-시-충돌-예측-l2) · [평가 코드](../laser/pure_rl_safety.py) |
| 예측 없이 6단계 개선 | PPO를 해당 단계에서 약 210만 스텝 추가 학습하고 새 배치에서 평가 | 단독 성공률 17.5% → 26.8%(보정 p = 0.0083). 순차 완주 410/1,000 → 516/1,000의 보정 p = 0.105. | [추가 학습 결과](results.md#충돌-예측-없이-6단계-추가-학습) · [평가 코드](../laser/level6_finetune_eval.py) |
| 재도전 없는 캠페인의 6단계 병목 | DAgger와 6단계 PPO 전문가를 고정하고, 동일 배치에서 6단계 예측 길이만 0.2초 → 0.3초 변경 | 두 배치군 완주 899/1,200 → 936/1,200(+3.08%p, 95% CI +1.19~+4.98%p). 세 번 시도 조건은 양쪽 599/600. 실패 표본 15건 중 13건에서 통과 경로를 재생했다. | [결과와 실패 분석](results.md#같은-캠페인-배치에서-6단계-예측-길이-비교) · [재현 절차](laser.md#동일-배치-6단계-후속-평가) |
